# Hot Wallet Manager

## Architecture

- `cmd/main.go` boots the service from `config.json`.
- `api/openapi.yaml` is the OpenAPI 3 contract.
- `api/api.gen.go` is generated by `oapi-codegen`.
- `internal/config` loads the JSON config.
- `internal/app` wires repositories, services, and handlers in the layered style.
- `internal/handlers` maps generated API request/response objects to service calls.
- `internal/services` contains HD derivation, validation, and signing logic.
- `internal/server` registers the generated strict `net/http` handler under `/api/v1`.
- `proto` holds 2 protobuf files from the original repository. Communication protocol with the core.

## How to Run

```shell
docker network create payment-gates-network
docker build . -t hwm
docker run -v "$(pwd)/config.json:/app/config.json:ro" -n hot-wallet-manager hwm
```
